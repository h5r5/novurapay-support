# مراجعة واقتراح تعريب واجهة تشغيل SupportPipe (Iraqi Arabic UI Localization Review)

> [!IMPORTANT]
> **وثيقة مراجعة فقط (Review Only):**
> تنفيذاً لمحددات المهمة 2.7 (Task 2.7)، تم حصر وتوثيق كافة نصوص الواجهة الحالية مع اقتراح بدائل عراقية مهنية وموجزة. **لم يتم تعديل أي سطر برمجي في الواجهة (`src/supportpipe/ui/app.py`)** لحين موافقة مالك المشروع واعتماد النصوص المقترحة.

---

## دوافع المراجعة (Rationale)
تستخدم الواجهة الحالية صياغات فصحى عامة ومترجمة آلياً تحمل بصمات الذكاء الاصطناعي (AI artifacts) مثل: *"مركز قيادة"*, *"كبسولة موحدة"*, *"المحركات متصلة"*. فرق العمليات وخدمة العملاء في البنوك والمحافظ الرقمية العراقية (مثل فرق الدعم في بغداد وأربيل) تستخدم مصطلحات مهنية مختصرة ومباشرة تمزج بين المصطلح التقني الدارج والعامية الإدارية السليمة.
